# Brain

Fall 2026 course materials, Rotman Commerce, University of Toronto. This repo is also an Obsidian vault.

| Folder | Class | What to add in Claude Projects |
|---|---|---|
| `ECO101/` | Principles of Microeconomics | `ECO101/Text` |
| `RSM100/` | Introduction to Management | `RSM100/Text` |
| `RSM219/` | Financial Accounting | `RSM219/Text` |
| `MAT133/` | Calculus and Linear Algebra for Commerce | `MAT133/Text` |
| `General/` | Academic policy, due-date calendar | `General/Text` |

Each class folder contains the original PDFs, PowerPoints and Word files sorted into subfolders (Slides, Workbooks, Problem Sets, and so on), plus a `Text/` folder with a Markdown copy of every file. Pick the `Text` folder in Claude Projects: it covers everything, every file is small, and it includes the PowerPoint content that Projects cannot read from `.pptx` files.

If you also want Claude to see the original PDFs (for diagrams and charts), add the class's PDF subfolders too. Skip `RSM100/Pre-Class Notes`: those PowerPoints are over the 30 MB limit.

`Home.md`, `Attachments/`, `Daily/` and `.obsidian/` belong to the Obsidian vault.
