Finding a Simpler Model
•Real-world problems are usually too complicated to solve if we considerall
factors present.
•Instead, we create amodelwhich is a simpler representation of the
real-world scenario.
•In this case, we can simplify the problem by considering only one or two
variables to adjust, while imagining all other factors to be constant.
